# FUGA+ Mobile

React Native + TypeScript mobile app for FUGA+.
- React Native
- TypeScript
- Expo (recommended)
- Plus Jakarta Sans
- Theme tokens from approved palette

## Setup

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env` and configure API URL
3. Run: `npx expo start`

## Design

Uses approved Stitch palette from assets/paleta_de_colores.md
